## 📌 Project Overview

Brain Tumor Prediction Using CNN-GNN is an intelligent medical image analysis system designed to detect and classify brain tumors from MRI images. The project combines the feature extraction capability of Convolutional Neural Networks (CNNs) with the relational learning capability of Graph Neural Networks (GNNs), resulting in improved prediction accuracy.

The system provides a user-friendly web application where users can upload MRI brain images and receive predictions regarding tumor presence and classification.

---

# 🎯 Objectives

- Detect brain tumors from MRI images.
- Improve prediction accuracy using a hybrid CNN-GNN architecture.
- Reduce manual diagnosis time.
- Build an easy-to-use web application for prediction.
- Assist healthcare professionals in preliminary diagnosis.
